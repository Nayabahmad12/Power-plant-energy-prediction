# Power Plant Energy Prediction using ANN

This project predicts power plant energy output using an Artificial Neural Network (ANN) built with PyTorch.

## Technologies Used
- Python
- PyTorch
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

## Features
- Data preprocessing
- Feature scaling
- ANN model training
- Energy output prediction
- Model evaluation using R² score

## Model Performance

R² Score:

```bash
0.93
```
